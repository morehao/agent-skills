# 任务
本命令由 `disk-cleanup` skill 的 **cleanup 分支**实现。

用 `skill` 工具加载 `disk-cleanup`，按 `SKILL.md` 的四步流程执行。默认只读：没拿到用户明确同意前，不跑 `--clean`，也不代删用户数据。

# 参数
$ARGUMENTS

> 可选清理范围，如「只看占用」「预览」「清理缓存」「本地数据库」。
> **若上方参数为空：不要执行任何脚本**，按 `SKILL.md` 第 0 步给出编号选项（只看占用 / 预览 / 实际清理 / 本地数据库 / 取消），等用户选择后再继续，不要替用户选默认项。
