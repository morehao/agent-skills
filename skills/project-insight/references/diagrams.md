# 图表：选型、校验与常见坑

> 由 SKILL.md 六步主干的 step 2 / step 5 按需加载。图是架构分析的主体之一：**结构图承载"谁在哪、依赖往哪走"，时序图承载"事情按什么顺序发生"**。

## 先选型，再画

| 图的职责 | 工具 | 理由 |
|---|---|---|
| 边界 / 分层 / 拓扑 / 部署 | **SVG**（走 `svg-maker` skill） | 位置即论据；自动布局会破坏"谁在底层、哪是边界" |
| 映射（多对多、二部图） | **SVG** | 需要人工重排两侧节点来消除交叉 |
| 左右对比（旧 vs 新 / A vs B） | **SVG** | 同构对齐本身承载语义 |
| 带回边的状态机 | **SVG** | 自动布局会把回边绕远、标签压线 |
| 时序 / 交互 | **Mermaid `sequenceDiagram`** | Mermaid 强项，不要升级成 SVG |
| 线性小流程（≤8 节点、无交叉） | **Mermaid `graph` / `flowchart`** | 纯文本、可 diff、易改 |
| 简单状态流转（边少） | **Mermaid `stateDiagram-v2`** | 够用即可 |

**升级阈值**：节点 ≥12，或含分叉/汇合/回边/泳道/分区，或需要表达纵向层次 → 用 SVG。同一张图不做两份。

## Mermaid：落盘前必须真解析

```bash
node scripts/check-mermaid.mjs <文档.md> [更多.md]
```

- 任一 `[MERMAID-ERROR]` 必须修到全 `OK`，不保留渲染报错的图；
- `[MERMAID-WARN]`（`<br>` 换行 lint）收敛为 0；
- 标签换行用不带斜杠的 `<br>`，只写在引号标签内（如 `A["网关<br>接入层"]`）；
- 依赖 `mermaid` + `jsdom`：首次在 `scripts/` 下 `npm install`（`node_modules` 不入库；复制注册的 skill 副本需重装）。

## SVG：交给 `svg-maker`，别自创样式

- 环境有 `svg-maker` skill 时**必须**用它（`architecture-svg` 用于拓扑，`clean-svg` 用于概念/流程）；没有时先说明再自绘。
- 自包含：内联 CSS、零外部资源（无 `<image>`、远程字体、JS、渐变）；
- `<title>` + `<desc>` 不带属性（`<title id="...">` 会被校验判缺失）；
- 根元素只写固定 `viewBox`，不写 `width`/`height`；
- 先画 connector 再画 node；盒内文字留 ≥24px 内边距，字号按层级统一；只用系统字体栈；
- 中文标点统一全角；文件用英文语义名，不用 `01-` 序号前缀。

## SVG 两道关：拓扑审计 + 目视

LLM 画的 SVG 有一个稳定失败模式：**标签全对，边连错了**（缺边、多边、分支挂错节点），缩略图看不出来。

```bash
node scripts/audit-svg-topology.mjs <图.svg> [--strict]
node scripts/render-svg-preview.mjs <图.svg>   # 展平 var() 后出 PNG，供目视
```

- 审计逐条打印「起点 → 终点」，与期望边清单核对；`[EDGE-DANGLING]`（>40px）是错误，`[EDGE-GAP]`（6–40px）是提示；
- 新画或重排后必须跑；`--strict` 可把提示级间隙也算失败；
- 预览必须走 `render-svg-preview.mjs`：librsvg 不解析 CSS 自定义属性，直接渲染会全黑。

## 图必须被正文包裹

- **图前有导读**：这张图是什么、为什么存在、看的时候注意什么；
- **图后有落着**：该看什么、代价是什么、下一步读哪；
- 只有一张图、没有正文的小节会被 `check-doc.mjs` 提示 `[FIGURE-ONLY]`；
- 正文不写"图 N"，SVG 的 `<title>` 里也不写序号——结构一改编号就失效。

## 多图批量产出

同一篇要出 ≥3 张 SVG 时，可以并行交给子代理，但每份规格必须给全：

| 必给项 | 说明 |
|---|---|
| 目标路径 | 绝对路径，一图一文件；明确"只写这一个文件" |
| 节点/边清单 | 直接给 Mermaid 源码或清单，写明"语义必须完全一致" |
| 布局要求 | 分几段/几列、每段放什么、跨段连线怎么走 |
| 风格块 | 整段 `<style>` 原样给出（含 `:root` 变量与暗色适配） |
| 自检要求 | XML 可解析、越界检查、逐盒文字宽度、贴出自检输出 |

主 agent 收尾：逐图跑拓扑审计 → 至少目视最复杂的一张 → 统一标点与命名 → 接入文档时补导读与着落。

## 常见坑

| 坑 | 表现 | 对策 |
|---|---|---|
| 结构图用 Mermaid | 加一个节点全图重排，边界语义丢失 | 结构/分层/拓扑一律 SVG |
| 时序图升级 SVG | 维护成本高、易错 | 时序用 `sequenceDiagram` |
| `<title id="...">` | 下游校验按标签名匹配，判缺失 | 写不带属性的 `<title>`/`<desc>` |
| 根元素带 `width`/`height` | 与其它资产不一致 | 只留 `viewBox` |
| 同批图三种画法 | 盒高、间距不一 | 规格里固定盒高与行距，复用坐标规则 |
| 预览全黑 | rsvg 不解析 `var()` | 用 `render-svg-preview.mjs` 展平后出图 |
| 图与正文两张皮 | 读者不知道看什么 | 补图前导读 + 图后落着 |
