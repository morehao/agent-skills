# AI Agent / LLM 应用

## 问题

1. Agent 循环长什么样：感知 → 规划 → 工具 → 观察 → 停止；停止条件是什么？
2. 上下文如何管理：窗口预算、压缩/摘要、检索回注、丢弃策略？
3. 记忆分几层（工作/情节/长期）？存在哪、何时读写、如何失效？
4. 工具如何定义、注册、执行？参数校验、超时、重试、错误如何回注？
5. 工具结果的信任边界：外部内容会不会被当成指令（提示注入）？
6. Skill/提示模板如何组织、发现、注入？与内置工具的关系？
7. MCP（或同类协议）接入哪些能力？transport、生命周期、错误治理？
8. 宿主接入协议（如 ACP）：session 生命周期、权限请求、流式更新、取消？
9. Runtime 与 Agent 循环的职责如何分离？沙箱、并发、资源限制在哪一层？
10. 会话/任务状态存哪？失败后如何恢复？多轮如何续接？
11. 评测怎么做：离线用例、回归门禁、人工抽检？如何防"看起来变好"？
12. 成本与延迟：token 预算、缓存、模型路由、降级策略？

## 典型决策

- 单 Agent vs 编排/多 Agent；
- 上下文压缩 vs 检索增强 vs 两者并用；
- 工具调用同步 vs 异步/流式；
- 权限在宿主侧还是 Agent 侧；
- 记忆持久化 vs 每次重建。

## 常见坑

- 把记忆写成表/缓存清单，不讲检索与失效；
- 只列"支持哪些工具"，不讲失败与结果回注；
- 把 MCP（Agent 接能力）与 ACP（宿主接 Agent）混为一谈；
- Runtime 与主循环混写，看不出引擎/策略边界；
- 没有评测，只凭 demo 判断效果。
